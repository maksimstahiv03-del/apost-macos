# Підключення APOST до TikTok (офіційний Content Posting API)

> Ця інтеграція перевірена автоматичними тестами на **локальному імітаторі** API, написаному за
> документацією TikTok. З реальним TikTok її ще не запускали: можливі відмінності. Якщо щось не
> спрацює, надішліть текст помилки з вікна та лог `~/Library/Application Support/APOST/logs/apost.log`.

## 1. Створіть застосунок у TikTok for Developers
1. Зайдіть на https://developers.tiktok.com та увійдіть своїм акаунтом.
2. **Manage apps → Connect an app** і створіть застосунок.
3. Додайте продукти **Login Kit** та **Content Posting API**; у Content Posting API увімкніть **Direct Post**.
4. Додайте дозволи (scopes): `user.info.basic`, `video.publish`, `video.upload`.

## 2. Redirect URI (обов'язково для десктопу)
У **Login Kit → Desktop → Redirect URI** додайте адресу, яку показує APOST у
**Налаштування → Акаунт TikTok** (за замовчуванням `http://127.0.0.1:8765/callback/`).
TikTok дозволяє для десктопу лише `localhost`/`127.0.0.1` із номером порту.
Якщо порт 8765 зайнятий, TikTok дозволяє шаблон `http://127.0.0.1:*/callback/`.

## 3. Ключі
Скопіюйте **Client Key** і **Client Secret** з сторінки застосунку й вставте в APOST →
«Зберегти ключі». Секрет зберігається **лише в macOS Keychain** (не у файлах).

## 4. Підключення
**Підключити акаунт** → відкриється браузер → підтвердьте доступ → APOST покаже «Підключено».
Кнопка **Перевірити доступ** показує, яку видимість публікацій дозволяє TikTok для акаунта.

## 5. Режими публікації
| Режим | Що робить |
|---|---|
| Ручний | Сповіщення + підготовка опису; ви публікуєте самі й підтверджуєте |
| Чернетки | Відео автоматично потрапляє в чернетки TikTok; ви публікуєте в застосунку TikTok |
| Пряма публікація | APOST публікує сам; «Опубліковано» лише після підтвердження від TikTok |

## 6. Важливі обмеження TikTok
* **Поки застосунок не пройшов аудит TikTok, публікувати можна лише з видимістю «Лише я».** Для публічних
  публікацій застосунок треба подати на перевірку (audit) у порталі TikTok. Це робиться поза APOST.
* Режим чернеток: не більше 5 відео в чернетках за 24 години та 6 запитів на хвилину на один токен.
* Є добовий ліміт публікацій через API на акаунт.
* До завершення перевірки застосунок працює в Sandbox: потрібно додати свій акаунт як тестового користувача.
